# Clean Core · Generador de correos

Aplicación React en JavaScript para preparar y validar correos del proceso Clean Core.

## Funciones

- Seis modos: integración, documento de cambio, OT de borrado, correo final, sin objetos y correo manual.
- Campos dinámicos y vista previa editable.
- Validación del documento contra la descripción de la OT de borrado.
- Confirmaciones obligatorias para transacciones desbloqueadas y definición `Decomisar` en Excel.
- Copia independiente de asunto, cuerpo o correo completo.
- Datos conservados únicamente en el almacenamiento local del navegador.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```
